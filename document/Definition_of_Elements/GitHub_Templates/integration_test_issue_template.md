## テンプレート使用方法

1. **Issue作成時**: 上記テンプレートをコピーして使用
2. **テスト実行時**: 「実行結果」セクションに結果を記入
3. **不具合発見時**: 「不具合情報」セクションに詳細を記入
4. **完了時**: Issueをクローズ
