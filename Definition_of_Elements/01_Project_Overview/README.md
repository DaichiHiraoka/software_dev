# プロジェクト概要

## 飲食店向け通信販売システム

このプロジェクトは、飲食店向けの通信販売システムを開発するソフトウェア開発コースの課題として作成されました。

### システム構成

- **フロントエンド**: React.js 19.1.0
- **バックエンド**: Node.js/Express.js
- **データベース**: SQLite
- **コンテナ化**: Docker & Docker Compose
- **開発支援**: Claude Code

### 主要機能

1. **顧客向け機能**
   - 商品カタログ閲覧
   - 商品検索・絞り込み
   - ショッピングカート
   - 注文処理

2. **管理者向け機能**
   - 注文受付管理 (Port 3001)
   - 会計管理 (Port 3002) 
   - 商品発送管理 (Port 3003)
   - システム管理 (Port 3004)

3. **バックエンド API**
   - REST API サーバー (Port 3005)
   - データベース管理
   - 画像アップロード機能

### アーキテクチャ

```
[顧客] → [React Frontend:3000] 
            ↓
[管理システム群:3001-3004] → [Express API:3005] → [SQLite DB]
```

### 開発環境

- Docker Compose による一括管理
- 各サービスの独立したコンテナ化
- 開発・本番環境の分離
