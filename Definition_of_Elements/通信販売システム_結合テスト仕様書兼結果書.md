## 1. 概要

### 本書の目的
本書は、通信販売システムのソフトウェア結合テストの仕様と結果を明確化し、複数のモジュール間の連携動作を確認することを目的とする。

### 本書の位置づけ
本書は通信販売システムの品質保証プロセスにおける結合テストフェーズの成果物である。

### 対象ユーザ
- 開発者
- テスト担当者
- 品質保証担当者
- プロジェクトマネージャー

### 記載範囲、記載内容
- API間の連携テスト
- フロントエンド-バックエンド間の結合テスト
- データベーストランザクション結合テスト
- エラーハンドリング結合テスト

### 参照ドキュメント
- 通信販売システム要件定義書
- ソフトウェア方式設計書
- 単体テスト仕様書兼結果書

### 定義（用語、略語）
- **API**: Application Programming Interface
- **JSON**: JavaScript Object Notation
- **ACID**: Atomicity, Consistency, Isolation, Durability

## 2. テスト概要

### 2.1 テスト方針

単体テストで確認された各モジュールの正常動作を前提として、複数のモジュール間の連携動作を確認する。特にデータの整合性、トランザクションの完整性、エラー伝播の適切性に焦点を当てる。

**テストに対する基本的な考え方:**
- データフローの検証
- インターフェース仕様の確認
- 異常系でのロールバック検証
- パフォーマンス要件の確認

### 2.2 テスト対象と範囲

**HWバージョン**: 開発環境（Windows/Linux）  
**ソフトウェアバージョン**: 
- Node.js: v18.x
- React: v18.x
- SQLite: v3.x

**ソフトウェア方式設計書バージョン**: Ver.1.0  
**テスト期間**: 2024年2月1日 ～ 2024年2月15日

**結合対象:**
- 商品管理 ↔ 在庫管理 結合
- 注文処理 ↔ 顧客管理 ↔ 在庫管理 結合
- 発送処理 ↔ 在庫更新 結合
- フロントエンド ↔ バックエンドAPI 結合
