# 開発ガイド

このディレクトリには、開発者向けのガイドライン、設定ファイル、開発環境関連の情報が含まれています。

## ファイル構成

### 開発指針・規約
- **CLAUDE.md** - Claude Code開発時の指針とベストプラクティス
- **add_point.md** - 追加機能・改善ポイントの記録
- **gemini.md** - Gemini AI関連の開発メモ

### 開発環境
- **環境変数設定**: 各環境での設定方法
- **ローカル開発**: 開発サーバーの起動方法
- **依存関係管理**: npm/yarnパッケージ管理

## 開発者向け情報

### 技術スタック
- **フロントエンド**: React 19.1.0, Tailwind CSS, shadcn/ui
- **バックエンド**: Node.js, Express.js, SQLite
- **開発支援**: Claude Code (claude.ai/code)

### コーディング規約
- **ESLint設定**: コード品質保証
- **Prettier設定**: コードフォーマット統一
- **TypeScript**: 型安全性の確保（一部）

### 開発ワークフロー
1. Claude Codeを使用した開発支援
2. Git によるバージョン管理
3. Docker による環境統一
4. 継続的インテグレーション
