# ユーザーマニュアル

このディレクトリには、各システムの操作マニュアルが含まれています。

## マニュアル一覧

### 顧客向けシステム
- **USER_MANUAL_Customer.md** - 顧客向けオンラインストア利用ガイド
  - 商品検索・カート・注文機能の使い方
  - アクセス: http://localhost:3000

### 管理者向けシステム

#### 注文管理システム (Port 3001)
- **USER_MANUAL_OrderManagement.md** - 注文受付管理マニュアル
  - 注文一覧表示・ステータス更新・顧客情報確認

#### 会計管理システム (Port 3002)  
- **USER_MANUAL_AccountingManagement.md** - 会計・支払い管理マニュアル
  - 支払いステータス管理・売上集計・入金確認

#### 発送管理システム (Port 3003)
- **USER_MANUAL_ShippingManagement.md** - 商品発送管理マニュアル  
  - 発送準備・配送状況追跡・配送完了処理

### 統合ガイド
- **SYSTEM_USAGE_GUIDE.md** - システム全体の利用ガイド
  - 各システム間の連携・ワークフロー・運用手順

## 対象ユーザー

- **顧客**: 商品購入を行う一般ユーザー
- **注文受付係**: 注文内容の確認・管理を行うスタッフ
- **会計係**: 支払い管理・売上管理を行うスタッフ  
- **発送係**: 商品の発送・配送管理を行うスタッフ
- **システム管理者**: 全体的なシステム運用を行う担当者

## 利用手順

1. 該当する役割のマニュアルを参照
2. システムへアクセス
3. マニュアルに従って操作実行
4. 問題が発生した場合は開発チームへ連絡
