## テスト実行基準

### 成功基準
- **API連携**: 正常なHTTPステータスとデータ連携
- **データ整合性**: 関連データの一貫性保持
- **エラーハンドリング**: 適切な例外処理と復旧

### エラー対応
- **通信エラー**: 再試行・フォールバック機能
- **データエラー**: トランザクション制御・ロールバック
- **UI連携**: エラー状態の適切な表示

## テスト環境準備

```bash
# 全システム起動
docker-compose up -d

# バックエンド起動
cd backend && node server2.js

# 各フロントエンド起動
cd frontend/src && npm start                    # Port 3000
cd order-management && npm start                # Port 3001  
cd accounting-management && npm start           # Port 3002
cd shipping-management && npm start             # Port 3003
cd admin-management && npm start                # Port 3004
```

- **➖ N/A**: 該当なし
