# run_all_tests.py 使用方法とテスト仕様書

## 概要

`run_all_tests.py`は、E-Commerceシステムの品質保証を自動化する完全自動テストシステムです。単体テスト、結合テスト、総合テストの3段階でシステム全体の品質を包括的に検証し、本番環境展開の判定を行います。

## 主要機能

### 🔧 自動化機能
- **サーバー自動起動**: 既存サーバー検出・新規起動の最適化
- **並列テスト実行**: 効率的なテスト実行管理
- **レポート自動生成**: CSV形式での詳細結果出力
- **品質判定**: 段階的成功基準による合否判定

### 📊 テスト階層
1. **単体テスト** (成功基準: 90%以上)
2. **結合テスト** (成功基準: 85%以上)  
3. **総合テスト** (成功基準: 80%以上)

---

## 使用方法

### 基本実行
```bash
cd test_list
python run_all_tests.py
```

### 実行条件
- **作業ディレクトリ**: `test_list`フォルダ内で実行
- **依存関係**: Python 3.7以上、aiohttp、requests
- **バックエンド**: Node.js サーバー (自動起動対応)

## エラーハンドリングとトラブルシューティング

### よくある問題と解決方法

#### 1. Unicode エラー
**症状**: `UnicodeEncodeError: 'cp932' codec can't encode`
**解決**: すべて修正済み。新しいバージョンを使用してください。

#### 2. サーバー起動失敗
**症状**: `[ERROR] Cannot start backend server`
**解決方法**:
```bash
# バックエンドサーバーを手動起動
cd ../backend
node server2.js

# 別ターミナルでテスト実行
cd test_list
python run_all_tests.py
```

#### 3. ポート競合
**症状**: サーバーが既に使用中
**解決**: 自動検出機能により既存サーバーを利用

#### 4. 依存関係エラー
**症状**: `ModuleNotFoundError`
**解決方法**:
```bash
pip install aiohttp requests
```

## 運用ガイドライン

### 推奨実行タイミング
- **開発時**: 機能追加・修正後
- **デプロイ前**: 本番環境展開前の最終確認
- **定期実行**: CI/CDパイプラインでの自動実行

### 結果の解釈
- **95%以上**: 優秀な品質
- **90-94%**: 良好な品質
- **85-89%**: 改善推奨
- **85%未満**: 修正必須

### CSV分析のポイント
- **response_time_ms**: パフォーマンス分析
- **error_message**: 失敗原因の特定
- **success**: 成功/失敗パターンの分析
- **timestamp**: 実行時刻の追跡

### 実行ログ活用方法
- **完全なコンソール出力**: CSVに記録されない詳細情報
- **色コード除去**: テキストエディタで見やすい形式
- **実行時間記録**: 各段階の実行時間の追跡
- **エラー詳細**: 失敗時の詳細なエラー情報
- **デバッグ支援**: 問題発生時の原因特定
