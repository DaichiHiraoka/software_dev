## テスト実行基準

### 成功基準
- **API**: 期待するHTTPステータスコードとレスポンス
- **フロントエンド**: 期待する画面表示と操作結果
- **データベース**: 期待するデータ変更と整合性

### エラーハンドリング
- **不正入力**: 適切なエラーメッセージ表示
- **ネットワークエラー**: フォールバック動作
- **データベースエラー**: トランザクション巻き戻し

## テスト環境準備

```bash
# バックエンド起動
cd backend
node server2.js

# 各フロントエンド起動
cd frontend/src && npm start          # Port 3000
cd order-management && npm start      # Port 3001
cd accounting-management && npm start # Port 3002
cd shipping-management && npm start   # Port 3003
cd admin-management && npm start      # Port 3004
```

- **✅ OK**: テスト成功

- **⚠️ 要確認**: 部分的成功、要調査
- **🔄 未実施**: テスト未実行
- **➖ N/A**: 該当なし
